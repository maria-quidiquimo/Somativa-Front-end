# 🐾 Projeto ONG de Adoção de Animais - Focinhos de Luz

Este é um projeto colaborativo desenvolvido para uma ONG de adoção de animais Focinhos de Luz.  
O objetivo é oferecer uma plataforma simples e intuitiva para que usuários possam conhecer os animais disponíveis para adoção e preencher um formulário de adoção.

---

## 🚀 Tecnologias utilizadas
- **Bootstrap** para estilização responsiva
- **HTML5** e **CSS3**
- **JavaScript** para interatividade

---

## 🎨 Paleta de cores
A paleta é minimalista e acolhedora, composta por:
- Roxo 
- Lilás
- Preto
- Branco

---

## 📑 Funcionalidades
- **Cards de animais**: cada card contém o nome e informações básicas dos animais disponíveis para adoção.
- **Formulário de adoção**: o usuário pode preencher seus dados para iniciar o processo de adoção.
- **Layout responsivo**: adaptado para diferentes tamanhos de tela.

## ⚙️ Como rodar o projeto
1. Clone este repositório:
   ```bash
   git clone maria-quidiquimo/Somativa-Front-end

2. Acesse a pasta do projeto:

    ```bash
    cd Somativa-Front-end

3. Abra o arquivo index.html em seu navegador ou utilize uma extensão como Live Server no VS Code para rodar localmente.
